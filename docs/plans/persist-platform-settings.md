# Plan: Persist platform settings in MySQL

- Schema: `platform_settings(settings_id TINYINT PK =1, settings_json JSON/LONGTEXT, updated_by INT NULL, updated_at TIMESTAMP)` via idempotent CREATE TABLE IF NOT EXISTS in `initMySQLSchema` (own try/catch). No seed row.
- Model (`adminModel.js`): `getPlatformSettings()` (parsed JSON or null; tolerate string/object), `savePlatformSettings(settings, updatedBy)` parameterized upsert (ON DUPLICATE KEY UPDATE).
- Service (`adminService.js`): replace in-memory state with `buildDefaultSettings()` (env read at call time), allowlist schema per section with type validators, `mergeSettings(defaults, stored)` (unknown keys dropped, read-only keys from defaults, secret-like keys stripped), `loadSettings()` (GET falls back to defaults if model throws; PUT does not). `updatePlatformSettings(patch, actor)` validates (422 `INVALID_SETTINGS` for non-object patch, unknown sections/keys, bad types/ranges, secret-like keys; read-only keys equal to current value are silently ignored), merges, saves, returns `{success,message,settings}`. test-email uses stored host/port, HTML-escaped.
- Controller: pass `request.auth` to update. Routes and response shapes unchanged.
- Validation ranges: general (platformName 1-100, supportEmail, defaultCompanyStatus enum, timezone, allowSelfRegistration, platformNotice <=500); security (jwtExpiresIn /^\d+[smhd]$/, minPasswordLength 6-128, requireSpecialChar, googleOAuthEnabled, cookieSameSite lax|strict|none, cookieSecure, sessionIdleTimeoutMinutes 5-1440); email (smtpHost, smtpPort 1-65535, smtpUser, senderName, requireTls; status read-only); aiEngine (defaultModel in availableModels, temperature 0-2, maxOutputTokens 1-32768, tokenQuotaPerTenantMonth>=0, sentimentAnalysisEnabled, autoTicketCategorization; availableModels read-only); infrastructure (region, maintenanceMode; environment, databaseHost read-only).
- package.json: `"test": "node --test test/"`.
- Tests: update `test/api/adminSettings.test.js` with mock adminModel: empty store defaults, stored override merge, PUT persists (fresh service sees it), 422 cases with no save, no secret leakage, partial update keeps other sections, model failure (GET fallback 200 / PUT 500), test-email uses stored host/port, auth 401/403. Optional model SQL test.
